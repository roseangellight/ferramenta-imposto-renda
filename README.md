# 📊 Organizador de Dados para Imposto de Renda - Excel

## 🎯 Objetivo do Projeto
Este projeto foi desenvolvido como parte do desafio da plataforma DIO. O objetivo é criar uma ferramenta robusta no Excel para organizar e reunir informações essenciais para a declaração de imposto de renda, garantindo um controle de entradas eficiente, validado e com interface amigável.

## 🛠️ Funcionalidades
- **Menu de Navegação:** Botões interativos para fácil transição entre as abas.
- **Validação de Dados:** Regras automáticas que evitam erros de digitação nos valores e datas.
- **Dashboard/Resumo:** Visualização clara das entradas e saídas.
- **Links Rápidos:** Acesso direto entre as abas e informações

## 💻 Como Utilizar
1. Faça o download do arquivo `Projeto Final.xlsx` neste repositório.
2. Abra o arquivo no Microsoft Excel (recomendado versão 2016 ou superior).
3. Navegue pelo menu inicial para acessar a área de lançamentos.
4. Preencha os campos (células desbloqueadas) com seus dados financeiros.
